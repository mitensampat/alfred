step 2 · your anthropic key

the brain, once.

this powers alfred's thinking. you create it once, paste it once, done. follow these in order.

2a

create an Anthropic account

sign up with the email you use most. if you already have one, just sign in.

open console.anthropic.com ↗
2b

add a little credit

go to Billing → Add credits. $5 is plenty to start — alfred uses pennies a day.

2c

create a key

go to API keys → Create Key. name it alfred so you remember what it's for.

2d

copy it now

it starts with sk-ant-. you won't be shown it again, so copy it somewhere safe for the next few minutes.

you'll paste this key into alfred in a moment — nothing to enter here. prefer the source? see Anthropic's official guide ↗.

step 3 · download & install

get alfred.

a 4 MB download, then a quick drag into Applications.

⬇ download for macOS
Coach-Alfred-2.3.0.dmg · 4 MB · macOS 13+
  1. open the file you just downloaded.
  2. drag alfred into Applications.
    [ looping gif: dragging Alfred.app into the Applications folder ]
  3. open alfred from your Applications folder.
signed & notarized by Apple — no scary warnings. if macOS hesitates, right-click alfred → Open once.
once alfred opens, setup continues inside the app — connecting your key, messages, calendar and Notion. keep your Anthropic key handy to paste.
