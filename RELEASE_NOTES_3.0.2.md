# Coach Alfred 3.0.2

A setup-focused release: getting Alfred running is now much faster, and the only things you *have* to provide are a Claude API key and your name.

## Setup asks for far less

- **Only the essentials are required.** The Claude key and your profile are the sole hard requirements. Permissions, WhatsApp, Google Calendar, and Notion are all now **optional** — connect them during setup or add them later from Settings, each with a "Skip for now."
- **Notion is optional.** Alfred's model is built from your messages, calendar, and browsing — Notion is an add-on, not a prerequisite. Setup completes without it.
- **iMessage retired.** WhatsApp is the primary message source; the messaging step is simpler and the standard WhatsApp database path is set for you.

## Smoother permissions

Full Disk Access — needed to read WhatsApp locally — now verifies reliably during setup, with a live status that flips to granted the moment you enable it in System Settings. The guided flow deep-links you straight to the right pane.

## Install

**Requires Apple Silicon (M1 or later).**

Download `Coach-Alfred-3.0.2.dmg`, drag Alfred to Applications, and launch. You'll be up and running with just a Claude API key and your name; grant Full Disk Access and connect WhatsApp when you're ready.

## Upgrading from 3.0.x

In-place upgrade — configuration and data carry over.
