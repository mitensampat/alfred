# Coach Alfred — Screenshot Manifest for Design Brief

## How to capture
Open each URL on your device (phone/tablet/desktop) and screenshot.
Base URL: `http://<your-ip>:8080/home.html?passcode=YOUR_PASSCODE`

---

## 1. Home — Evening Wrap-up (Mobile)
**What it shows:** Pinned #1 goal with Done/Change buttons, coaching observation card (Relationship type), observation dots with expandable list, quick-action buttons (Calendar/Overdue/Nudge/Focus), chat input with "/" hint
**Viewport:** Mobile (375x812)
**URL:** Load home.html after 5pm

## 2. Home — Observations Expanded (Mobile)
**What it shows:** Multiple coaching observation cards (Leverage, Follow Through, Attention, Focus types) each with colored dot indicators and method attribution (Relational Method, Direct Method)
**Action:** Tap the "6 more observations" expander

## 3. Focus Card with Follow Through (Mobile)
**What it shows:** A different pinned goal (Focus type), coaching observation about relationship trust risk with actionable advice
**Action:** Scroll down after expanding observations

## 4. Calendar Tool Card (Mobile)
**What it shows:** User message bubble, structured calendar card (date, event count, time-dot list of meetings), coaching commentary below calling out double-bookings and focus time
**Action:** Tap "Calendar" quick action or type "what's on my calendar?"

## 5. Overdue Commitments Card (Mobile)
**What it shows:** Commitments tool card showing 7 items with direction arrows (outbound/inbound), owner labels, coaching response highlighting relationship debt
**Action:** Tap "Overdue" quick action

## 6. Settings — Configurations / Cadences (Mobile)
**What it shows:** Bottom sheet with tabs, cadence list (Morning Briefing, Attention Check, Todo Scan, etc.) each with schedule, last-run time, and Run button
**Action:** Tap gear icon, configurations tab

## 7. Settings — Tenets (Mobile)
**What it shows:** Coaching tenets with toggle switches (Alfred Rules, Relational Rules, Direct Rules, Voice & Tone) each with Edit/expand controls
**Action:** Tap tenets tab

## 8. Settings — Coaching Skills (Mobile)
**What it shows:** User-created skills (Deep Work Guard, Energy Audit, Follow Through) with Edit/Delete buttons, toggle switches, data source tags, frequency labels
**Action:** Tap coaching tab

## 9. Settings — Skill Library (Mobile)
**What it shows:** Installable skills marketplace (Weekly Review, Relationship, Leverage, Follow Through) with author attribution, descriptions, data source requirements
**Action:** Tap library tab

## 10. Pin Selector with Search (Mobile)
**What it shows:** Search input field, list of open commitments with person names, status (waiting/overdue), Pin buttons, "Show all tasks" link at bottom
**Action:** Tap "Change" on pinned goal

## 11. Chat Conversation — Coaching Response (Mobile)
**What it shows:** User message bubble ("what should I focus on tomorrow?"), AI coaching response referencing specific overdue tasks with priority reasoning, trust level indicator (deep)
**Action:** Type a coaching question in chat input

## 12. Slash Commands Menu (Mobile)
**What it shows:** Commands popup with icons (/calendar, /commitments, /messages, /focus, /nudge, /briefing, /settings, /skills)
**Action:** Type "/" in chat input

## 13. Desktop Layout
**What it shows:** Full-width layout, same content as mobile but with wider cards and typography
**Viewport:** Desktop (1280x800)

## 14. Tablet Layout
**What it shows:** Intermediate layout between mobile and desktop
**Viewport:** Tablet (768x1024)

---

## Design Language Reference
- **Canvas:** #f8f7f4 (warm off-white)
- **Surface:** #ffffff (cards)
- **Ink:** #1b2a4a (primary text)
- **Ink-2:** #5c6370 (secondary text)
- **Line:** #e4e2dc (dividers)
- **Coach accent:** #1b2a4a (dark navy)
- **Growth:** #2d5a3d (green, for positive)
- **Warning:** #c49a3c (amber)
- **Danger:** #8b2332 (red, overdue)
- **Font:** System font stack (serif for "coach alfred" title)
- **Card style:** White surface, subtle border (#e4e2dc), 12px border-radius
- **User bubble:** Dark navy (#1b2a4a) with white text, right-aligned
- **AI response:** Left-aligned plain text, no bubble
